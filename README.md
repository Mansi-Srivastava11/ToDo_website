# 📝 Todo Backend API

A scalable and modular **RESTful Todo Backend API** built using **Node.js, Express.js, MongoDB, and Mongoose**.

This project provides a complete backend system for creating, reading, updating, and deleting Todo tasks through RESTful API endpoints. It follows a clean and organized backend architecture with separate configuration, controllers, models, routes, and middleware.

---

## 🚀 Project Overview

The **Todo Backend API** is designed to provide a reliable backend service for managing Todo tasks.

The application uses **Node.js** as the runtime environment, **Express.js** for building the REST API, and **MongoDB with Mongoose** for storing and managing Todo data.

The project also includes asynchronous error handling and centralized error middleware to make the application easier to maintain, debug, and extend.

## 📁 Folder & File Description

### `config/`

Contains configuration-related files.

### `config/db.js`

Responsible for establishing the connection between the application and MongoDB database.

---

### `controllers/`

Contains the business logic of the application.

### `controllers/todo.controller.js`

Contains the controller functions responsible for handling Todo operations such as:

- Creating Todos
- Getting Todos
- Getting a Todo by ID
- Updating Todos
- Deleting Todos

---

### `middleware/`

Contains reusable middleware functions.

### `middleware/asyncHandler.js`

Handles errors generated by asynchronous controller functions and helps avoid repetitive `try...catch` blocks.

### `middleware/error.middleware.js`

Provides centralized error handling for the Express application.

---

### `models/`

Contains Mongoose database models.

### `models/todo.model.js`

Defines the Todo schema and creates the Mongoose model used to interact with MongoDB.

---

### `routes/`

Contains the API route definitions.

### `routes/todo.routes.js`

Defines the routes related to Todo operations and connects them with the appropriate controller functions.

---

### `server.js`

The main entry point of the backend application.

It is responsible for:

- Creating the Express application
- Configuring middleware
- Connecting to MongoDB
- Registering API routes
- Starting the server

## ⚙️ Installation & Setup

### Step 1: Clone the Repository

```bash
git clone https://github.com/Mansi-Srivastava11/todo-backend.git
```

### Step 2: Open the Project

```bash
cd todo-backend
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Configure Environment Variables

Create a `.env` file:

```env
MONGO_URI=mongodb://localhost:27017/todo_db
PORT=3001
```

### Step 5: Start MongoDB

Make sure your local MongoDB server is running.

### Step 6: Start the Backend Server

```bash
node server.js
```

If a development script is configured in `package.json`, you can also use:

```bash
npm run dev
```

# 🔗 API Documentation

## Todo API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/todos` | Create a new Todo |
| `GET` | `/api/todos` | Get all Todos |
| `GET` | `/api/todos/:id` | Get a Todo by ID |
| `PUT` | `/api/todos/:id` | Update a Todo |
| `DELETE` | `/api/todos/:id` | Delete a Todo |

---

## ➕ Create Todo

### Request

```http
POST /api/todos
```

### Example Request Body

```json
{
  "title": "Learn Node.js",
  "description": "Study Express.js and MongoDB"
}
```

### Purpose

Creates a new Todo and stores it in the MongoDB database.

---

## 📋 Get All Todos

### Request

```http
GET /api/todos
```

### Purpose

Returns all Todo items stored in the database.

---

## 🔍 Get Todo by ID

### Request

```http
GET /api/todos/:id
```

### Example

```text
GET /api/todos/64abc123
```

### Purpose

Returns a specific Todo using its MongoDB ID.

---

## ✏️ Update Todo

### Request

```http
PUT /api/todos/:id
```

### Example Request Body

```json
{
  "title": "Learn MERN Stack",
  "description": "Complete Node.js, Express.js and MongoDB",
  "completed": true
}
```

### Purpose

Updates an existing Todo using its MongoDB ID.

---

## 🗑️ Delete Todo

### Request

```http
DELETE /api/todos/:id
```

### Purpose

Deletes a Todo from the MongoDB database using its ID.

# ⚡ Middleware & Error Handling

The project includes dedicated middleware for handling asynchronous operations and application errors.

## Async Handler

The `asyncHandler.js` middleware is used to handle errors from asynchronous controller functions.

This keeps controller code clean and reduces repetitive error-handling code.

---

## Error Middleware

The `error.middleware.js` file provides centralized error handling.

Instead of handling errors separately in every route, errors can be passed to the centralized error middleware.

```text
Controller
     │
     ▼
Async Handler
     │
     ▼
Error Middleware
     │
     ▼
Error Response
```

- Using environment variables

- Separating routes and controllers
